数値予報の天気図は、デスクトップアプリで

地上天気図（気圧配置）、500 hPa 高度、850 hPa 気温、ジェット気流、降水量 — ECMWF の数値予報を自分の PC に取得して、全球から日本周辺まで描きます。

このサイトは、気象業務法のため予報図を載せていません。以前ここにあった GFS の予報図 （850 hPa 気温など）の代わりに、デスクトップアプリ AIseed Weather で同じ種類の図を描く方法をまとめました。

描ける図

地上天気図（気圧配置）

海面更正気圧の等圧線に、降水量や 10 m 風を重ねます。高気圧・低気圧の配置、 等圧線の混み具合、台風の中心気圧と経路を、予報時間を進めながら追えます。

高層天気図

1000〜50 hPa の 13 面の、ジオポテンシャル高度・気温・風速・湿度・鉛直流・渦度。 500 hPa 高度でトラフとリッジ、850 hPa 気温で寒気・暖気の流れ込みを見ます。

ジェット気流

250 hPa・300 hPa の風速で、ジェットの位置と強さ。

降水・雲・大気の状態

積算降水量・降水強度・降水タイプ・全雲量・可降水量・最不安定 CAPE・2 m 気温・突風など、 ECMWF Open Data の 185 要素。

全球予報図と地域

全球・北極中心・南極中心・日本周辺・東アジア・北太平洋・北大西洋・ヨーロッパ・北米・ アジア・アフリカ・南米・オセアニアの 13 の範囲から選べます。

予報時間と動く地図

解析（T+0）から 240 時間先まで（00・12 UTC の初期値。144 時間までは 3 時間ごと、その先は 6 時間ごと）。 「動く地図」では GPU で描き、拡大・移動しながら風の粒子を流して再生できます。

旧サイトの GFS の図との対応

旧サイトの図アプリで選ぶもの
850 hPa 気温（/Gfs/Temperature/850）レイヤー「850hPa気温」
500・925 hPa 気温レイヤー「500hPa気温」「925hPa気温」
北極域の 500・850 hPa 気温（/Gfs/TemperaturePoler/…）地域「北極中心」＋ レイヤー「500hPa気温」「850hPa気温」
300・500・850 hPa の風（/Gfs/Wind/…）レイヤー「300hPa風速」「500hPa風速」「850hPa風速」
降水量（/Gfs/Precip）レイヤー「積算降水量」「降水強度」

モデルは GFS ではなく ECMWF の IFS（HRES、0.25°）です。GFS などほかのモデルは計画中です。

使い方

  1. 入れる

    Linux（macOS も同じ手順）で、Miniforge（conda-forge）を使います。動く地図を使うなら、 部品入りの実行環境を一度だけ作ります（約 1 分）。 
    git clone https://github.com/aiseed-dev/weather.git
cd weather
mamba env create --prefix ./.venv -f environment.yml
mamba activate ./.venv
pip install -e .
tools/build_client.sh        # 動く地図を使うとき（一度だけ）
flet run

  2. 取得元を選ぶ

    初回の起動で ~/.config/aiseed-weather/config.toml ができます。どこから予報を取るかは アプリが勝手に決めないので、ここで選んでから起動し直します。日本からは Google Cloud のミラーが速い。 
    forecast_source = "ecmwf_gcp"   # ほかに "ecmwf_aws"・"ecmwf_azure"・"ecmwf_direct"

  3. データを取る

    下のタブの モデル を開き、左の GPV データ で初期時刻を選んで 取得 を押します。1 時刻分が約 150 MB で、 取り終えた時刻から描けます。取得するのはこのボタンを押したときだけで、 手元に取ったデータは次からそのまま使います。

  4. 図を選ぶ

    左の 地域 で範囲を、レイヤー で要素を選びます。 下のスライダーと ▶ で予報時間を進め、上の 図 ／ 動く地図 で描き方を切り替えます。

図には、データの出典（ECMWF Open Data、CC-BY-4.0）と初期時刻・予報時間を描き込みます。 このアプリは公開されている数値予報のデータを可視化する道具で、予報を発表するものではありません。 防災の判断には、気象庁の警報・注意報などの情報を使ってください。
