AIseed Weather

個人開発気象ツール

地上天気図（気圧配置）・高層天気図・全球予報図・降水ナウキャストを、自分のパソコンで描くデスクトップアプリです。

ECMWF の数値予報と気象庁の観測を、自分で取得して描きます。無料・オープンソース（AGPL）。

入れ方を見る 数値予報の天気図を描く（使い方） GitHub

できること

全球予報図

ECMWF Open Data（IFS）から、海面気圧・500 hPa 高度・850 hPa 気温・ジェット気流などを描きます。 使い方

気候値とアノマリ

ERA5（1940 年〜）を基準に、現況が平年からどれだけ離れているかを図にします。ここがこのアプリの差別化点です。 （開発中。いまは地点予報の平年値を Open-Meteo の過去データから出しています）

日本の現況

気象庁の高解像度降水ナウキャスト（過去 3 時間と 1 時間先まで、全国と地方の図）と、 AMeDAS 約 1,300 地点の地上観測を、「いまの日本」の層として描きます。

観測の記録（1880 年〜）

このサイトが配っている日別の観測データを読み、任意の日の地点ランキング、 任意の期間・閾値の日数や極値・平均・合計、1 地点の推移を図と表にします。図は出典つきの PNG で保存できます。

注釈と重ね描き

等圧線や風を、気温場・降水の上に重ねて描きます。気圧面は 1000〜50 hPa の 13 面 （ジオポテンシャル高度・気温・風・湿度・鉛直流・渦度）。（予定）テキストや矢印による注釈。

エクスポート

図には出典・ラン時刻・ライセンスを描き込みます。観測の記録の図と地点予報のグラフは、 そのまま PNG で保存できます。（開発中）予報図・ナウキャストの図の保存。

動く地図とアニメーション

予報ステップをタイムラインで連続再生できます（⏮ ▶ ⏭ とスライダー）。 「動く地図」では GPU で描き、拡大・移動しながら風の粒子を流せます。ナウキャストも 5 分ごとのコマで再生できます。

入れ方

パソコンの OSいまの状況
Linux動作を確かめている環境です。下の手順で動きます
macOS同じ手順で動きます
Windowsまだ確かめていません（動く可能性はありますが、手順を用意していません）
スマートフォン・タブレット使えません（パソコンのアプリです）

cartopy・cfgrib・eccodes が C ライブラリ（PROJ / GEOS / eccodes）に依存するため、 pip ではなく Miniforge（conda-forge）を使います。環境はリポジトリ内に ./.venv として作るので、グローバル環境を汚しません。 

git clone https://github.com/aiseed-dev/weather.git
cd weather
mamba env create --prefix ./.venv -f environment.yml
mamba activate ./.venv
pip install -e .
tools/build_client.sh        # 動く地図を使うとき（一度だけ）
flet run

初めて起動すると ~/.config/aiseed-weather/config.toml ができます。どこからデータを取るかは アプリが勝手に決めないので、ここで選んでから起動し直します。数値予報の取得元の選び方と画面の操作は 数値予報の天気図を描くにまとめています。

解析用のサンプル Jupyter ノートブック（ECMWF GRIB2 の直接読み込み、AMeDAS スナップショット、 ERA5 気候値など）も同梱しています。

想定している利用者

MSL、ジオポテンシャル高度、アノマリが何を指すかをご存じの方に向けた道具です。 用語を噛み砕いたり、単位を「やさしく」言い換えたりはしません。ラベル・単位・図法は、 あなたが既に読み慣れた慣例に従います。入門のしやすさではなく、専門ワークフローの最適化が設計方針です。

知っておくべき 2 つの設計原則

1. データソースはあなたが選ぶ

どのミラーを使うか、ERA5 にどう接続するかは ~/.config/aiseed-weather/config.toml で決めます。 アプリが勝手に選ぶことも、設定ウィザードを出すこともありません。

2. 取得はあなたの操作時だけ

ビューを開く・更新を押す・パラメータを変える。この 3 つ以外で通信しません。 バックグラウンドポーリングも自動更新も先読みもありません。

この 2 つは、法的な立ち位置でもあります。 データを取得するのも、図を作るのもあなたの手元です。当ツールは 気象データを可視化する道具であり、予報を生成して配信するものでは ありません。だから個人開発気象統計（気象庁の観測値だけを 扱うサイト）とは違い、ECMWF や ERA5 を扱えます。
これは思想であると同時に、データ提供元への礼儀でもあります。キャッシュを効かせ、必要なときだけ取得し、 User-Agent でアプリ名を正直に名乗ります。

4 つのデータ層

役割の違うデータを 1 つのワークフローに束ねている点が、このアプリの中心的な価値です。

データソースとライセンス

層ソース役割ライセンス・出典
予報グリッドECMWF Open Data未来 / 地図表示CC-BY-4.0
気候値・アノマリERA5過去の文脈CC-BY-4.0
日本の現況気象庁 レーダー・AMeDASいまの日本出典: 気象庁ホームページ
日本の観測の記録気象庁の日別値（このサイトが配る NetCDF）1880 年からの記録出典: 気象庁ホームページ（編集・加工）
地点予報Open-Meteo補助的な地点表示CC-BY-4.0

帰属は省略できません。 書き出す図には、データの出典・ラン時刻・図法・（アノマリなら）基準期間を必ず入れます（予報図の保存は開発中）。 図を共有した相手から「これは何のデータ?」と聞かれたとき、図そのものが答えられる状態にしてあります。 気象庁データを合成・加工した場合は、その旨と編集責任の所在も併記します。

このサイトとの関係

このサイト「個人開発気象統計」は、気象庁の観測データを誰でもすぐ読める形にまとめたものです。 一方 AIseed Weather は、自分の手で天気図を作りたい人のための道具です。 既製のチャートでは変数や見た目が物足りない、現況を過去の気候値と比べたい、 注釈をつけて誰かに説明したい — そういう用途のために作っています。

一緒に作る

天気予報の道具は、使う人が協力して作ると、いいものができます。 予報のデータは各自が自分の手元に取り、図の作り方やコードの改善は GitHub で共有してください。 自分の AI と一緒にアプリを作るやり方は、同じ作者の aiai（AI 時代の学び方）にまとめています。
