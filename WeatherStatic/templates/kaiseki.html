アクセス解析と外部送信

このサイトは、サイトをよくし、見る人に合った案内を出すために、ページを見たときの記録を {{ to_host }} に送っています。送り先は、このサイトの運営者が管理するサーバーです。 記録をほかのサービスに渡すことはありません。

送る情報

いつ送る情報
ページを開いたとき ページの URL のパスと題、来る前のサイトのホスト名（ページの URL までは送りません）、 キャンペーンの印（URL の utm_ で始まる値）、ブラウザーの言語、時間帯、 画面の大きさ、ブラウザーと機器の種類（User-Agent）
ページを離れたときそのページを見ていた時間（秒）
受け入れた人だけ このサイトの Cookie（kaiseki_id、約 400 日）に置いた番号と、 訪問ごとの番号（タブを閉じると消えます）。受け入れたことも記録します

IP アドレスは記録しません。番号は乱数で、名前やメールアドレスとは結び付いていません。

受け入れる・受け入れない

最初に開いたとき、画面の下で「受け入れる」か「受け入れない」かを聞きます。

  • 受け入れた人には番号を置き、その番号で、同じ人の記録をまとめます
  • 受け入れない人には番号を置かず、ページが見られた数だけを数えます
  • 同じ運営者のサイト（{{ kaiseki.own | replace(" ", "・") }} のサイト）どうしのリンクをたどると、 番号を引き継ぎます。番号は URL の # の後ろに載せるので、サーバーには送られません。 一方のサイトで受け入れた人は、もう一方でも受け入れた扱いになります

選び直す・自分の記録を見る・消す

読み込み中…


    

    
ブラウザーの開発者向けの画面では、kaiseki.choose(true)（受け入れる）・
        kaiseki.choose(false)（受け入れない）・kaiseki.forget()（番号と記録を消す）
        でも同じことができます。自分の記録は {{ kaiseki.to }}/v1/mine?vid=番号 で見られます。
        ブラウザーの Cookie を消すと、番号も消えます（送り先の記録は残るので、先に「自分の記録を消す」を押してください）。

  • 合った案内を出す: よく見る地点や季節に合わせて、このサイトや同じ運営者のサービスの案内を出す
